# Osaka Tsunami 3D Simulator — 大阪市津波 3Dシミュレーター (PLATEAU × Three.js)

`memo.md` の要求に基づき、宮古津波シミュレーター (Miyako Tsunami) の物理・3Dアーキテクチャを発展させ、**「大阪湾から大阪市・大阪港ベイエリアへの津波来襲、三大水門（安治川・尻無川・木津川水門）および防潮堤の治水・防御機能」**を観察・解析できる高精度3Dシミュレーターです。

---

## 主な機能と特徴

### 1. 大阪市・大阪港ベイエリアの精緻な3Dモデル化
* **ハイブリッド高精度標高モデル (DEM, 大阪市全域 24×21.6km・15mメッシュ)**:
  * 陸地標高・海陸判定: 国土地理院 DEM5A/DEM10B。海域と河川（淀川・安治川・木津川・尻無川・道頓堀川・大川 等）は DEM の欠測域として正確に抽出し、夢洲・舞洲・咲洲などの人工島、T.P.0m 未満のゼロメートル地帯（西淀川・此花・港・大正 等）をそのままの標高で再現。
  * 海底地形（水深）: `DOCS/japan.tif`（15秒角）から大阪湾の水深を取得し、岸壁・河道は -3m 以上の水深に接続。
* **周辺地形（広域背景）**:
  * `N60_osaka_viewer/docs/osaka.tif`（1秒角 DEM）と国土地理院航空写真で、大阪平野・六甲山地・生駒山地・金剛山麓・大阪湾岸（約63×56km）を背景メッシュとして表示（表示設定で切替）。
* **PLATEAU 3D都市モデル (大阪市全域建物)**:
  * `N60_osaka_viewer` の建物インデックスデータ（61万棟）から、計算範囲（大阪市全域）の建物を約34,000棟に間引いて配置。
  * 浸水深（0.5m以上）に応じて建物が警戒色（赤）にリアルタイム変化。
* **国土地理院高精細航空写真 (seamlessphoto)**:
  * 夢洲（万博会場）、舞洲、咲洲（コスモタワー）、天保山（海遊館）、大阪都心部の航空写真を地形メッシュにテクスチャマッピング。

### 2. 南海トラフ巨大地震波源CSV連携 (nankai_trough対応)
* **nankai_troughアプリ出力CSV完全互換**:
  * `nankai_trough` アプリが出力した境界波形CSV（Time, Elevation, U, V, Speed, Direction 等）をドラッグ＆ドロップまたはファイル選択で直接読み込み可能。
  * メタデータ（地点名、最大波高、到達時間、継続時間、来襲方向）の自動解析。
* **プリセット波源（nankai_trough の実計算）**:
  * nankai_trough（全国2.5kmメッシュ）で内閣府(2012)ケース①〜⑤と全域連動M9.1を3時間計算し、大阪湾の水位が最大となったケース③「紀伊半島沖～四国沖」を採用。
  * 本領域の西端（135.345°E, 34.655°N）の波形を、nankai_trough と同じ「市街地連携用トリミング」形式と「全期間」形式で収録。最大 2.04m（地震後 2:09:45）。
  * 各ケースの大阪湾での最大水位: ①1.63m ②2.04m ③2.04m ④1.86m ⑤1.74m 全域連動1.85m（計算領域西端）。2.5kmメッシュのため湾奥の増幅は詳細計算側（本アプリ）で扱う。
  * 再生成: `tools/nankai/run-nankai.ts`（ヘッダー参照）→ `node tools/build-wave-sources.mjs`
* **仮想ケース（波源計算ではない正弦波）**:
  * 仮想 想定超過津波（沖合4.5m）: 防潮堤越流・ゼロメートル地帯浸水の検証用。
  * 安政南海地震型（1854年・概略 沖合2.5m）: 水門全開時の河川遡上の観察用。
* **カスタム津波パラメータ**:
  * スライダーで沖合波高（1〜30m）、周期、来襲方向を自由に変更。

### 3. 大阪三大水門 & 防潮堤の治水・防御検証機能
* **三大水門（アーチ型防潮水門）**:
  * 安治川水門（設計天端高 T.P. +7.4m）
  * 尻無川水門（設計天端高 T.P. +6.7m）
  * 木津川水門（設計天端高 T.P. +7.2m）
* **海岸防潮堤・河川護岸（水域マスクから自動生成）**:
  * 水門の外側（大阪湾・港湾・淀川等）に面する陸地: 防潮堤 T.P. +6.8m
  * 水門の内側（安治川上流・堂島川・土佐堀川・大川・道頓堀川・木津川/尻無川上流）に面する陸地: 河川護岸 T.P. +3.5m
  * 三大水門の位置は `tools/build-seawalls.mjs` で河道断面に自動フィットし、全閉時に内側河川網が湾から完全に切り離されることを検証。
* **水門・堤防プリセット & 可変スライダー**:
  * 「三大水門：全閉（防護成功）」
  * 「三大水門：全開・未閉鎖（河川遡上・市街地氾濫検証）」
  * 「防潮堤・水門なし（自然海岸）」
  * 「防潮堤・水門高さスライダー可変（0m 〜 15m）」

### 4. 物理シミュレーション (Web Worker)
* **浅水長波・局所慣性モデル**:
  * Bates et al. (2010) / de Almeida et al. (2012) の θ重み付きフラックス（隣接フラックスの空間平均）、フルード数リミッタ、ポジティビティリミッタ。
  * CFL条件に基づく自動時間刻み（Adaptive dt）。
* **造波・吸収境界（リラクゼーションゾーン）**:
  * 湾側（西端・南端）の開けた海域 400m 帯で水位と流量を入射波へ緩和し、港からの反射波は領域外へ抜ける。河口には造波帯を置かない。
  * 波源CSV／シナリオの波高は湾端（沖合）での入射波として与え、港内での反射・増幅は本アプリで計算する。
  * `Direction_deg` は nankai_trough の仕様どおり流向（向かう方位）として扱い、流速 0 の行では無視（既定の南西 235° から来襲）。
* **マルチスレッド計算**:
  * Web Worker によるバックグラウンド物理計算により、60fps の滑らかな Three.js 3D描画と操作性を維持。

### 5. 観察・解析・動画録画機能
* **地点観察 & 浸水ハイドログラフ**:
  * 地図上をクリックすると、その地点の地盤標高・現在水深・最大浸水深と、時系列水深変化グラフを表示。
* **リアルタイム被害・治水メーター**:
  * 経過時間、沖合津波高、最大遡上高、浸水面積（ha）、浸水建物棟数。
* **住所・地名から地点指定**:
  * 国土地理院の住所検索（ネット接続が必要）。番地まではピン、町名・丁目までは e-Stat 町丁境界で範囲を赤線表示し、範囲内（陸地）の最大水深を時系列表示。
* **CSV出力機能**:
  * 結果CSV: 10秒ごとの沖合津波高・最大遡上高・浸水面積・浸水建物（画面と同じ経過時間・地震後時刻）。
  * ハイドログラフCSV: ピン／範囲の水深の時系列（地点観察パネルの「CSV」）。いずれも UTF-8 BOM付き。
* **MP4動画録画機能**:
  * `mp4-muxer` + WebCodecs による 3D H.264 MP4 動画エクスポート。
* **多言語対応**:
  * 日本語 / English 完全バイリンガル切り替え。

### 6. 計算 → タイムライン再生
* 「▶ 計算・再生」で波源の全期間を計算（CSV波源は最大波の半分に達する5分前から最後まで、仮想ケースはシナリオの継続時間）。計算済みの範囲は計算中でもすぐ再生できる
* 計算結果は30秒ごとに記録し、タイムラインのスライダーで任意時刻へジャンプ、10〜300倍速で早回し・巻き戻し
* 時刻表示は計算開始からの経過時間と、CSV波源では地震発生後の時刻を併記
* 海面の上下を5倍に強調表示（表示のみ・切替可）
* MP4録画は計算済みの全期間を15秒の動画に収め、経過時間・地震後時刻・沖合波高・浸水面積・浸水建物を焼き込む

### 6b. 詳細タイル（2m・全建物、入れ子計算）
* ピンや範囲を置いた場所に 1/2/3 km 四方の 2m タイルをアプリ内で作成（`src/tile/tilebuilder.js`、N65 nagoya_flood と同じ方式）。作ったタイルはブラウザ（IndexedDB）に保存し、一覧に ★ 付きで表示（選んで「削除」で消せる）
  * 地形: 国土地理院 DEM5A（5m）を 2m に補間し、PLATEAU 建物の底面高で補正。海・川は DEM5A の欠損のうち 15m 格子の水域とつながるもの、水底は 15m 格子から
  * 建物: PLATEAU API（3次メッシュごとの CityGML、LOD1）。間引きなし
  * 航空写真: 地理院タイル（0.5m/画素）
* 防潮堤・河川護岸・三大水門は 15m 計算と同じ設定（全閉／全開／なし／高さ可変）を 2m 格子に置き直す
* 「詳細計算 (GPU)」: 全域（15m）の計算結果の水位を、タイル外周の境界条件として時間・空間補間して与え、タイル内を WebGL2 で計算（局所慣性式・仮想パイプ配置、`src/tile/tileSim.js`）。全域の計算がまだなら自動で始め、タイルは全域の計算済みの時刻までを追いかけて同時に進む（nagoya_flood と同じ）
* 再生は全域のタイムラインと同期。タイル内は 2m の水面と全建物（周囲の水深0.5m以上で赤）を表示し、浸水面積・浸水建物・最大浸水深をパネルに表示。ピン／範囲がタイル内なら地点観察グラフは 2m の結果（[2m] 表示）
* 浮動小数点テクスチャへの描画（EXT_color_buffer_float）に対応した GPU が必要

### 7. 自由視点カメラ
* 左ドラッグ: 回転 / 右ドラッグ: 平行移動 / ホイール: カーソル位置へズーム
* ダブルクリック: その地点を回転・ズームの中心に（注視点移動）
* W/A/S/D・矢印キー: 前後左右移動、Q/E: 下降/上昇（Shift で高速）
* 視点プリセット: 全景 / 大阪港 / 三大水門 / 市街地 / 広域 / 真上
* クリック: 地点観察ピン（ハイドログラフ表示）

## データ生成

```bash
node tools/build-regions.mjs     # ground.f32 / water.u8 / aerial.jpg（GSI DEM + japan.tif）
node tools/build-seawalls.mjs    # 三大水門（--check out.jpg で内側河川網を画像出力）
node tools/build-labels.mjs      # ランドマークラベル
node tools/build-outer.mjs       # 周辺地形（osaka.tif + 航空写真）
node tools/build-wave-sources.mjs
node tools/sim-headless.mjs sluice_closed 60   # ヘッドレス検証（浸水面積・越流の推移）
```

## 起動方法

```bash
cd osaka_tsunami
npm install
npm run dev
# ブラウザで http://localhost:5176/ を開く
```
